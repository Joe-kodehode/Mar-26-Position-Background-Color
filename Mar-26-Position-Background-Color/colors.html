CSS Colors

This page shows different ways to write colors in CSS

Named Colors

CSS includes color names like red, blue, green, purple and chartruse

background-color: chartruse
background-color: fuchsia

Hex

Hex colors start with a # and use numbers and letters from 0-F

The numbers / letter represent Red, Green and Blue values.

The first two are Red, Middle two are Green and last two are Blue.

#222222

RGB

RGB stands for Red Green and Blue

RGB is represented by numbers from 0-255

rgb(34, 197, 94)

RGBA

RGBA is like RGB, but the A controls transparency.

rgba(255, 45, 100, 1)

HSL

HSL stands for Hue, Saturation and Lightness

hsl(280, 70%, 55%)

oklch

What “OKLCH” stands for

O → Perceptual lightness (how light/dark a color looks to humans)

K → (part of the OK color space name, from Oklab)

L → Lightness

C → Chroma (color intensity / saturation)

H → Hue (the actual color angle, like red, blue, etc.)

oklch

Text Color and Background Color

We can color the text with color and the background with background-color.
